# 配一套自己发的电（离网光伏配置单）

把「要带哪些电器、每天各用多久」换算成一张能照着买的配置单：组件买多大、电池买多大、控制器与逆变器要什么规格；并能回答「阴雨天能撑几天」和「我手上这块板加这块电池能带什么」。

体验地址：https://xululu0401.github.io/offgrid-kit/

## 结构

| 文件 | 作用 |
|---|---|
| `index.html` | 单文件应用（由 `build.cjs` 把 `template.html` + `core.js` + `ui.js` 拼出来） |
| `core.js` | 纯计算内核（`window.AppCore`），不碰 DOM，可在 node 里直接 require |
| `ui.js` | 界面层（`window.OffgridKitUI`），负责渲染、持久化与四种导出 |
| `template.html` | HTML 骨架与全部样式（占位符 `/*CORE*/`、`/*UI*/`） |
| `build.cjs` | 拼装 index.html |
| `tests/core.test.cjs` | 核心测试：`node --test tests/core.test.cjs` |
| `make-cover.cjs` | 生成 1200×1200 封面（取值来自同一次引擎运行） |

## 口径（详见批次目录的 `需求与调研.md`）

- 能量统一在**电池母线侧**：交流负载的取电量先除以逆变器效率。
- `etaSys`（系统综合效率）覆盖组件温度/灰尘降额、控制器、线损、电池往返，**不含逆变器**（逆变器单独算），这样不会把同一份损失扣两遍。
- 峰值日照小时数**由使用者填写**，本页不联网、不查任何地区的真实日照数据。
- 装机按单块规格**向上取整**，因此晴天日发电恒 ≥ 日耗电。
- 阴雨期逐日递推；小数自持天数按比例分摊到最后一个半天，余额比较带 1e-9 相对容差。

## 不做什么

不做电气安全设计（线径/断路器/接地/防雷/压降）；不做组串电压匹配与 MPPT 工作点；不推荐品牌、不给购买链接；不预测真实发电量（逐日天气与季节变化不建模）；不处理并网、余电上网与多路充电；不做电池寿命预测。**不替代专业设计。**

页面上的默认场景与预设都是虚构示例，不是实测数据。
